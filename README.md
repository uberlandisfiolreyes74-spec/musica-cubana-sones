# musica-cubana-sones# música-cubana-sones

Repositorio oficial del proyecto **Sones de Hoy**, un álbum de música cubana contemporánea inspirado en la realidad actual de Cuba. Incluye letras originales, estructura del álbum y archivos para el futuro sitio web donde se promocionará y comercializará el proyecto musical.

## Contenido
- Letras completas de las canciones
- Diseño conceptual del álbum
- Archivos del sitio web (próximamente)
- Portada del proyecto
- Recursos de marketing

## Objetivo del proyecto
Crear un producto musical profesional basado en son cubano y salsa contemporánea, con distribución digital y presencia online profesional (GitHub Pages).
